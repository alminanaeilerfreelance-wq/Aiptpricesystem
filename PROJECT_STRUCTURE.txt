QUICK REFERENCE
===============

KEY APP ROUTER FILES TO UNDERSTAND:
- app/layout.tsx                              → Root shell and metadata
- app/(dashboard)/layout.tsx                  → Sidebar + protected dashboard shell
- app/api/**/route.ts                         → Backend API handlers
- models/Quotation.ts                         → Main quotation model
- utils/quotation-calculator.ts               → Core fee calculation logic
- pdf/quotation-template.ts                   → Quotation PDF generation

CORE BUSINESS MODULES:
- Quotations (create, edit, approve, export PDF, send email)
- Services, Countries, Procedures, Client Types, Pricing Rules
- Reports (quotations + revenue)
- Settings (company, currency, taxes, SMTP)

DATA FLOW (APP ROUTER)
======================

1. USER INTERACTION
   └─→ app/(dashboard)/quotations/new/page.tsx

2. FORM SUBMISSION
   └─→ services/quotations.service.ts (Axios)

3. API PROCESSING
   └─→ app/api/quotations/route.ts
   └─→ lib/mongodb.ts
   └─→ models/Quotation.ts + related models

4. RESPONSE
   └─→ React state/query update
   └─→ UI re-render
   └─→ Updated dashboard/table display

IMPORTANT NOTES
===============

AUTH + SECURITY:
- JWT authentication
- Password hashing with bcryptjs
- Protected route middleware
- Role-based access control

TABLE STANDARDS:
- Sticky headers
- Search + filters + pagination
- Compact rows and right-aligned currency
- Status badges (Approved/Pending/Draft/Rejected)

FEE SCHEDULE PAGES:
- /quotations/fee-schedules/trademark
- /quotations/fee-schedules/patent
- /quotations/fee-schedules/design
- Dynamic procedures in header
- Country rows with image flags
- Fee columns: Official Fee, Attorney Fee, Total

DEPLOYMENT:
- Vercel recommended
- MongoDB Atlas for production database
- SMTP required for email quotation sending
- ENV variables required in .env.local

DEVELOPMENT COMMANDS
